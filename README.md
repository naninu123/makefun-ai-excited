Paper Plane Giant: a colossal paper airplane the size of a jumbo jet soaring between skyscrapers at golden sunset, three real passenger jets flying alongside it for scale and trailing ribbons of aurora light — made to get make.fun's AI judge excited.

## Run it

```sh
python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`), verifies the bytes match, and checks the file is a JPEG or PNG under the 1 MiB cap. No network, fully deterministic: two runs write identical bytes.
